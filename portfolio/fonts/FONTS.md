# Fonts embedded in the portfolio images

All three families are licensed under the SIL Open Font License 1.1 (full texts alongside this file).
Files are the Latin-subset WOFF2 builds distributed by the Fontsource project (package version 5.3.0 for each family).

| Family | Used for | Files |
|---|---|---|
| Instrument Serif | headlines and large figures | `instrument-serif-latin-400-normal.woff2`, `-400-italic.woff2` |
| Hanken Grotesk | body text | `hanken-grotesk-latin-400/500/600-normal.woff2` |
| IBM Plex Mono | data, labels, code | `ibm-plex-mono-latin-400/500-normal.woff2` |
